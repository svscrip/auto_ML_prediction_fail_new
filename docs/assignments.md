Это проверка работоспособности на малой выборке, не новая оценка полного
baseline и не замена чисел карточки. Длительность и качество smoke могут
зависеть от среды; текущие артефакты остаются в исключённом из Git `artifacts/`.

Повторить проверку:

```powershell
poetry sync --with dev
poetry check --lock
poetry run pre-commit run --all-files
poetry run pytest -q --override-ini addopts=''
poetry run python -m src.predict --output-dir artifacts/smoke_test
poetry run python -m src.model_card --check model_card.md --metrics artifacts/example_model_card_metrics.json
```

Локальный полный тестовый прогон включает smoke на 2 000 и 5 000 строках;
обучение на всех 136 114 строках в рамках этих проверок не выполнялось.
Исторические числовые таблицы карточки относятся к исходному полному прогону.
